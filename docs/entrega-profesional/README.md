## Como usarla

1. Lee primero `16 - Documento maestro de entrega para cliente` si necesitas
   un handoff consolidado, legible y listo para maquetar en Word.
2. Usa `10 - Auditoria del repo` para saber que falta cerrar o que riesgos
   siguen abiertos.
3. Usa `01` a `15` como anexos y soporte formal del documento maestro.
4. Mantiene estos archivos sincronizados con cambios de producto,
   seguridad, migraciones y despliegue.
5. Revisa `adrs/` cuando una decision estructural cambie la arquitectura o el
   contrato entre UI, datos y operacion.
