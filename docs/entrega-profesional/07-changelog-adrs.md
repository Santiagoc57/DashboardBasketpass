# Changelog y ADRs

## Objetivo

Dejar rastro de decisiones importantes y cambios relevantes.

## Changelog

Debe registrar:

- fecha.
- version o hito.
- que cambio.
- impacto.
- migraciones asociadas.
- acciones manuales.

## ADR

Cada decision de arquitectura importante deberia guardar:

- contexto.
- decision.
- opciones descartadas.
- consecuencias.

## Decisiones que valen ADR

- uso de Supabase como backend.
- estrategia de permisos con RLS.
- estructura de auditoria.
- estrategia de timezone.
- estrategia de adjuntos.
- estrategia de storage.
